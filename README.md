# 2차 - 자동차 경주

## 구성 🛠

* 기능 명세의 기능은 일반적인 처리와 `IllegalArgumentException`을 던질 **예외 상황**의 처리로 나뉜다.
* 💭 이모지가 붙은 기능은 요구사항에 기재되지 않았지만 스스로 판단하여 구현한 부분이다.
* 구현된 기능은 체크 표시
---

## 기능 명세 ✏

### 경주용차 이름 입력

- [ ] 입력 프롬프트는 다음 형태로 시작한다.
- [ ] `,`으로 구분하여 경주용차 이름 입력
- [ ] 구분된 경주용차 이름에서 양쪽 공백 제거 💭 (사용자 입력 편의 고려)
- 이름에 특수문자는 허용

#### 입력 형식
```text
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)   
[쉼표(,) 로 구분된 입력] 
```

- 예시
```text
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)   
pobi,woni,jun 
```

#### 예외 상황

- [ ] 입력된 자동차가 0대
- [ ] 중복되는 자동차명 💭
  - 예: `pobi,pobi,jun`
  - 우승한 자동차 식별이 가능해야 함
- [ ] 각 경주용차 이름 길이가 5를 초과
- [ ] `,` 사이에 공백이 든 경우 💭
    - 예: `pobi,,jun`, `pobi, ,jun`
    - 요구 사항에는 '각 자동차에 이름을 부여할 수 있다'라고 했다. 하지만 빈 문자열 자체는 경주용차의 이름으로 보기 어렵다고 판단하였다.
    - 길이가 0이니 5자 이하 이름을 만족하지만 유효한 이름에만 한정짓기로 하였다.

### 시도 횟수 입력

- [ ] 차들의 이동 횟수를 자연수로 입력 받는다.
- [ ] 입력의 양쪽 공백 제거 💭 (사용자 입력 편의 고려)


#### 입력 형식
```text
시도할 횟수는 몇 회인가요?
[양의 정수 입력]
```
예시:
```text
시도할 횟수는 몇 회인가요?
5
```

- 예외 상황
  - [ ] 숫자가 아닌 입력
  - [ ] 음수 또는 0 입력
  - [ ] 소수 입력
  - [ ] `int` 범위 초과

### 경주
- [ ] 다음 규칙따라 자동차를 입력한 시도 횟수만큼 반복
  - 각 자동차마다 0 ~ 9 사이의 무작위 값 뽑기
  - 대상 차는 4 이상이면 전진, 아니면 정지
- [ ] 각 라운드마다 모든 자동차의 이동상황 출력
  - 형식: `자동차이름 : --` (전진한 만큼 - 표시)

#### 출력 형식
- 경주 과정 출력
```text
실행 결과
[라운드 결과 1]

[라운드 결과 2]

...
```
- 라운드 결과 출력
```text
[경주용차 이름] : [이동 횟수]
```
- 예시
```text
실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --
  
pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----
```

### 우승자 출력

- [ ] 경기 완료 후 우승자 출력. 여러 명이면 `,`로 구분 
- [ ] 아무도 완주 못한 경우 제일 멀리 간 자동차만 출력 💭
  - '우승자는 한 명 이상일 수 있다'라고 하여 우승자가 없는 경우는 없도록 해야 한다고 판단

#### 출력 형식

```text
최종 우승자 : [쉼표로 구분된 우승자 목록]
```

- 예시
```text
최종 우승자 : pobi, jun
```
